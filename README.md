# dsh-design-tokens · 设计令牌命名规范参考

纯 Node 实现，无网络、无外部服务。

## 安装

```bash
dsh plugin add dsh-design-tokens
```
安装后在 profile 的 `package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-design-tokens"`。

## 安装

```bash
dsh plugin add github:uckkk/dsh-design-tokens
```

> 安装即在本机运行第三方代码，请自行审阅源码。
